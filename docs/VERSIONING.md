# Versioning

AGGRO follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## While Baatorasaka (0.x)

Stay on **0.x** until Floor 1 closes and a post-Baatorasaka baseline is intentional.

| Bump | When |
|------|------|
| **Minor** (`0.N.0` → `0.N+1.0`) | Player-facing features, gates, loot tables, combat verbs, economy loops that ship. |
| **Patch** (`0.N.M` → `0.N.M+1`) | Fixes, copy/balance tweaks, art wiring, docs — no new loop surface. |

`0.1.0` is the first tagged playable cut of the Baatorasaka loop. Changelog entries live in [CHANGELOG.md](../CHANGELOG.md). Design truth that is still moving belongs in [EARTHFALL_STATE.md](EARTHFALL_STATE.md) — version bumps document what shipped, not what is parked.
